# Student Gradebook Management System

## 📌 Project Description

The **Student Gradebook Management System** is a Python-based application that helps manage student marks and academic performance. It allows users to add student records, calculate average marks, assign grades, view all students, and search for a particular student.

This project demonstrates the use of Python functions, dictionaries, loops, conditional statements, exception handling, and user input.

## ✨ Features

- **Add Student:** Enter a student's name and marks in three subjects.
- **Marks Validation:** Ensures that marks are between 0 and 100 and rejects invalid inputs.
- **Grade Calculation:** Automatically assigns grades based on the student's average marks.
- **View Students:** Displays all registered students, their marks, averages, and grades.
- **Search Student:** Search for a student by name.
- **Interactive Menu:** Provides a simple, menu-driven interface.

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Concepts:** Functions, dictionaries, loops, conditional statements, and exception handling

## 🚀 How to Run the Project

### Prerequisites

- Python 3 installed on your computer.

### Steps

1. Download or clone this repository to your computer.
2. Open the project folder in Visual Studio Code.
3. Open the terminal in VS Code.
4. Run the following command:

```bash
python gradebook.py
```

5. Follow the menu instructions displayed on the screen.

## ⚠️ Limitations

- Student records are stored in memory and are lost when the program exits.
- Student names are case-sensitive during searches.
- The current version does not support editing or deleting student records.
